# Security Policy

## Supported versions

Only the latest Nyanbin release receives security fixes. Deployments should update promptly and should not expose development builds to untrusted networks.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include live secrets, note links, delete tokens, passwords, or plaintext in any report.

Use the repository host's private vulnerability-reporting feature when it is enabled. If no private channel is shown, contact a project maintainer through the repository host and ask for a private reporting channel without disclosing technical details. The project intentionally does not embed an unconfirmed security address or external reporting URL here.

Include the affected version, impact, reproduction steps using synthetic data, and any suggested mitigation. We will acknowledge receipt, investigate, coordinate a fix and disclosure, and credit reporters who request it.
